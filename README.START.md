**Kurzstart (Windows)**

1. Claude Code CLI installieren und einloggen (einmalig):
   `irm https://claude.ai/install.ps1 | iex`, dann `claude` starten und `/login` ausführen.
2. App bauen: `.\scripts\build_exe.ps1`
3. Verknüpfungen anlegen: `.\scripts\install_shortcuts.ps1`
4. „AI Coach“ im Startmenü öffnen, unter „Profil & Ziele“ Garmin verbinden.

Zum Entwickeln ohne Build: `.\venv\Scripts\python app.py`
